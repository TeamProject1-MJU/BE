// 플랫폼: iOS 앱, 카카오 로그인. 경로 API: 카카오맵 REST API(혼자 이동 6.1의 경로·요금, 대중교통 경로 조회). AI: OpenAI API
// 다익스트라(우리 그래프)는 중간역 선정과, 6.1·약속역 경로에서 카카오 호출이 실패했을 때의 대체 경로에만 쓴다. 각자 그 역까지 실제 경로는 카카오맵 REST API(6.1)로 찾고 응답은 저장하지 않는다
// 표지판 촬영·AI 이동 방향 안내: 개념설계서에 저장 요구 없음 -> 테이블 없음(요청 시 처리 후 폐기)
// 혼잡도 5단계(쾌적/여유/보통/혼잡/매우 혼잡)와 라벨은 AI가 계산한 값을 그대로 congestion_level·congestion_level_label에 저장(MOCK은 적재 시 같은 기준으로 채움), 서버는 다시 계산하지 않음
// 요금: 혼자 이동(6.1)은 카카오맵 REST API 응답 요금을 쓴다. 중간역 추천과 6.1 카카오 실패 시 대체 경로에서만 RIDE 간선 distance_m 합으로 서버가 자체 계산(예상 요금, 저장하지 않음)
// enum 컬럼은 varchar + CHECK로 만든다. DBML로 표현할 수 없는 CHECK·부분 유니크 인덱스는 linkro_constraints.sql(DDL)에 둔다

  congestion_level       varchar(12) [not null, note: 'COMFORTABLE/RELAXED/NORMAL/CROWDED/VERY_CROWDED. PREDICTED는 AI 파일 값 그대로, MOCK은 적재 시 같은 기준으로 채움. 쾌적 [0,35), 여유 [35,50), 보통 [50,100), 혼잡 [100,150), 매우 혼잡 [150,∞) (하한 포함·상한 미포함, pct와 일치 CHECK)']
